# PepTrack Pro - App Store Screenshots

## Screenshot Summary

All screenshots have been captured in mobile dimensions (390x844px) suitable for app store listings.

### Screenshots Captured:

1. **01_home_calendar.png** - Home screen with weekly calendar view
   - Shows: Greeting, adherence ring, week calendar, today's schedule, recurring items

2. **02_add_recurring.png** - Add Recurring Item modal
   - Shows: Name input, category selection, dosage, route, recurrence options

3. **03_calculator.png** - Peptide Calculator
   - Shows: Syringe size selector, vial amount, BAC water, dose calculation, visual syringe

4. **04_research.png** - Research Database
   - Shows: Search bar, AI Web Search button, peptide/medication tabs, compound cards

5. **05_journal.png** - Health Journal
   - Shows: Log & Entries/Trends toggle, Log Today button, recent entries section

6. **06_profile.png** - Profile & Settings
   - Shows: Guest user, Google sign-in option, theme toggle, preferences, data management

7. **07_home_dark.png** - Home screen in Dark Mode
   - Shows: Same as #1 but with dark theme applied

8. **08_calendar_month.png** - Month Calendar View
   - Shows: Full month grid, today highlighted, schedule below

## How to Download Screenshots

The screenshots are displayed in the Emergent Agent interface. To save them:

1. Right-click each screenshot image above
2. Select "Save Image As..."
3. Save with the corresponding filename

Alternatively, re-run the screenshot capture locally after downloading the project.
