## App Store Connect Upload Instructions
1. Go to App Store Connect → Your App → App Information
2. Click "Screenshots" under each device size
3. For **iPhone 6.7" Display**, upload all 8 screenshots
4. Arrange in order: Home → Calculator → Research → Journal → Profile → Dark modes
5. Save changes
